# Neon Aether website

Static, Netlify-ready website built from supplied visual assets and developer-confirmed public game information.

## Deploy
Copy the contents of this folder into the GitHub repository connected to the existing Netlify site. Keep the current Netlify site configuration.

## Preserved integrations
- Google Analytics 4: `G-WECZMC36GJ`
- Google Search Console verification meta tag
- Netlify Forms waitlist (`name="waitlist"`, `data-netlify="true"`)

## Accuracy notes
- No unconfirmed launch date, price, or unsupported platform list is published.
- No unverified character portraits are fabricated; character dossiers are interactive text cards.
- The unedited Andrew turnaround sheet in the supplied package is deliberately excluded.
- Supplied key art and environment assets are retained in `assets/`.
